# grok-trial-wordcount

`wordcount` 是一个命令行工具，用来统计文本里的中文字符数和英文单词数，并估算阅读时间（秒）。支持从文件或标准输入读取 UTF-8 文本，运行时只依赖 Python 标准库，需要 Python 3.10 及以上。

## 安装

```bash
pip install .
```

安装完成后即可使用控制台命令 `wordcount`。

开发时可以连同测试依赖一起安装：

```bash
pip install -e ".[dev]"
pytest
```

## 用法

### 从文件读取

准备文件 `article.txt`，内容为：

```text
你好，世界！This is a well-known example. Don't skip it.
```

运行：

```bash
wordcount article.txt
```

输出：

```text
中文字数: 4
英文词数: 8
阅读时间: 0 秒
```

这段原文只有 3.2 秒，按「四舍五入到 10 秒、满 5 秒才进位」会得到 0 秒。更长的文本才会显示非零时间，例如 150 个汉字正好是 30 秒：

```bash
python -c "print('汉' * 150)" | wordcount
```

```text
中文字数: 150
英文词数: 0
阅读时间: 30 秒
```

### 从标准输入读取

```bash
cat article.txt | wordcount
```

也可以直接用管道：

```bash
echo "你好 world" | wordcount
```

输出：

```text
中文字数: 2
英文词数: 1
阅读时间: 0 秒
```

不传路径时从标准输入读取。文件不存在时，程序会在标准错误输出说明原因，并以非零状态码退出。

## 计数规则

- **中文字符**：只统计汉字，即 CJK 统一表意文字及常见扩展区（扩展 A–I，含扩展 G、H）。标点、数字和空白不计入。
- **英文单词**：连续的 ASCII 字母算作一个单词。像 `don't`、`well-known` 这样的缩写和连字符词，每个算一个单词。
- **阅读时间**：单位是秒。原始秒数 = `中文字符数 / 300 × 60 + 英文单词数 / 200 × 60`，也就是每个汉字 0.2 秒、每个英文单词 0.3 秒。再四舍五入到最接近的 10 秒；恰好落在 5 秒（如 5、15、25 秒）时向上取整。计算使用整数运算，避免浮点误差。空文本或没有任何可计数内容时为 0 秒。不足 5 秒的短文本同样会舍入为 0 秒。例如 300 个汉字为 60 秒，25 个汉字（正好 5.0 秒）为 10 秒。
